# 数据源说明

Mstock 后续需要通过代码获取美股 / ETF 股票池和日线行情数据。

## 当前状态

项目默认保持离线。用户明确允许本轮联网后，可使用云端小批量入口获取真实公开日线；仅执行源码验收时不请求行情。

## 后续原则

- 只使用公开、合规的数据源。
- 获取数据前需要用户明确允许联网。
- 数据获取过程需要记录数据来源、获取时间、频率和缓存位置。
- 原始数据存放在 `data/raw/`。
- 清洗数据存放在 `data/processed/`。
- 缓存数据存放在 `data/cache/`。

## 云端小批量接续

复用项目已存在的yfinance及Yahoo Chart兜底、Stooq备用行情实现；源网站的可用性和限流情况以每次执行结果为准，不能用模拟数据替代失败的真实下载。

每轮记录获取时间、日线频率、实际数据来源、缓存输入SHA256和最新完整交易日。下载缓存仅用于独立临时目录中的本轮计算，原始日线不进入公有仓库提交或报告附件；附件保留派生的候选、图表与失败记录。请求池和风险范围见[云端使用说明](CLOUD_USAGE.md)。

云端入口不获取旧电脑私人校对，不连接券商，不自动交易；没有新增付费接口或项目密钥。
