## 2. 字段含义

| 字段 | 含义 |
| --- | --- |
| 排名 | 按综合评分和规则优先级排序后的序号。 |
| 代码 | 美股、ETF 或杠杆 ETF 的交易代码。 |
| 名称 | 标的中文或原始名称，优先展示用户可读名称。 |
| 市场 | 标的所属市场，例如美股。 |
| 是否ETF | 标记该标的是否为 ETF。 |
| 是否杠杆ETF | 标记该标的是否为杠杆 ETF，若为是，必须附带风险标签。 |
| 最新收盘价 | 最近一个交易日的收盘价。 |
| 当日涨幅 | 最近一个交易日相对前一交易日的涨跌幅。 |
| 5日涨幅 | 最近5个交易日累计涨跌幅。 |
| 10日涨幅 | 最近10个交易日累计涨跌幅。 |
| 20日涨幅 | 最近20个交易日累计涨跌幅。 |
| 60日涨幅 | 最近60个交易日累计涨跌幅。 |
| 成交量 | 最近一个交易日成交股数或数据源提供的成交量。 |
| 成交额 | 最近一个交易日估算或数据源提供的成交金额。 |
| 20日量比 | 最近成交量相对20日平均成交量的比例。 |
| MA5乖离 | 最新收盘价相对 MA5 的偏离程度。 |
| MA10乖离 | 最新收盘价相对 MA10 的偏离程度。 |
| MA20乖离 | 最新收盘价相对 MA20 的偏离程度。 |
| 距离20日新高 | 最新收盘价距离20日最高价的比例或差值。 |
| 距离60日新高 | 最新收盘价距离60日最高价的比例或差值。 |
| 距离120日新高 | 最新收盘价距离120日最高价的比例或差值。 |
| MACD状态 | MACD 多头、红柱扩大、钝化、走弱等状态描述。 |
| 相对QQQ强度 | 标的相对 QQQ 的强弱表现。 |
| 相对SPY强度 | 标的相对 SPY 的强弱表现。 |
| 趋势结构分 | 均线排列、价格位置和趋势方向的评分。 |
| 突破强度分 | 阶段新高、平台突破和突破质量的评分。 |
| 量能强度分 | 成交量、成交额和量比的评分。 |
| 相对强度分 | 相对 QQQ / SPY 的强弱评分。 |
| 主升浪形态分 | 是否符合主升浪加速和截图偏好的形态评分。 |
| 风险扣分 | 因高波动、过热、杠杆 ETF、流动性不足等因素产生的扣分。 |
| 综合评分 | 各项评分扣除风险后的总分，范围为0到100分。 |
| 等级 | A+、A、B、C、D 五档候选等级。 |
| 入选理由 | 标的进入候选列表的中文原因。 |
| 风险标签 | 需要人工复核的中文风险提示。 |
| 观察价 | 用于复盘观察的关键价位，不是买入建议。 |
| 失效位 | 用于判断形态削弱或破坏的参考价位，不是止损指令。 |
| 我的校对 | 用户人工校对结果。 |
| 我的备注 | 用户人工备注。 |
| 是否加入观察池 | 用户是否将该标的加入观察池。 |
| 是否实际交易 | 用户是否基于个人判断进行了实际交易。 |
| 交易结果 | 用户自行记录的交易结果，仅用于复盘。 |

## 3. 等级字段说明

- A+：85 分以上，核心主升浪候选。
- A：75 到 84 分，强趋势候选。
- B：65 到 74 分，观察候选。
- C：50 到 64 分，形态不完整。
- D：50 分以下，不符合风格。

## 4. 入选理由标准文本

入选理由应优先使用以下中文短语：

- 均线多头排列
- 突破20日新高
- 突破60日新高
- 接近120日新高
- 放量突破
- 成交额放大
- MACD红柱扩大
- 强于QQQ
- 强于SPY
- 收盘接近日高
- 主升浪加速
- 平台突破
- 回踩MA10后转强

## 5. 维护要求

新增用户可见字段时，必须同步更新本文件、报表模板和相关测试。

## 6. 云端小批量运行字段

`数据检查.csv`使用以下字段，不改变既有候选评分字段：

| 字段 | 含义 |
| --- | --- |
| 代码 | 本轮请求的股票或基准代码。 |
| 状态 | 数据检查通过、不可用、参与评分或排除。 |
| 最新交易日 | 排除未完成日线后的最新完整交易日。 |
| 有效行数 | 通过日期和数值检查的完整日线数量。 |
| 数据来源 | 缓存记录的现有行情提供者。 |
| 输入SHA256 | 本轮下载缓存原始字节的SHA256；原始缓存不放入报告附件。 |
| 说明 | 下载缺失、质量异常或与基准日期不一致的原因。 |

`运行摘要.json`与`运行说明.md`还记录：运行状态、获取时间、源码版本、请求股票、数据频率、完整日线上限、原始缓存位置、下载成功数量、下载失败数量、行情基准日期、评分输出数量、B级及以上数量、图表数量、参与评分股票、排除股票、评分摘要、数据来源及失败原因。评分摘要沿用代码、最新交易日、综合评分与等级字段。

运行状态“完整接通”表示指定批次的行情、计算和图表链路完成；“部分接通”表示只完成了部分指定股票；两者均不代表全市场覆盖、收益承诺或交易许可。B级及以上数量仅按现有等级统计，不改变评分门槛。

## 7. 独立存储股多样本验证字段

本节仅用于`research/memory_validation`研究产物，不改变原候选评分。

| 字段 | 含义 |
| --- | --- |
| 完成次数 | 在该时间分段内已结束的模拟观察次数；每标的同时仅一笔。 |
| 盈利次数 | 扣除往返成本假设后净收益严格为正的完成记录数；保本不计赢。 |
| 净胜率 | 盈利次数除以完成次数；无完成记录时为空，不写成0%。 |
| 胜率95%区间 | Wilson二项近似区间；相关性可能低估不确定性。 |
| 未结束按不赢处理的胜率区间 | 将尚未结束记录加入分母并按未盈利做保守检查，避免只排除未结束亏损。 |
| 月份区块胜率95%区间 | 按模拟开始月份分块、固定种子重采样2000次；不足12个月时为空。 |
| 每次平均净收益 | 已完成记录的平均净收益，非年化账户收益。 |
| 平均盈利和平均亏损 | 完成记录中净正收益、净负收益分别的算术均值。 |
| 盈利亏损总额比 | 所有正净收益之和除以所有负净收益绝对值之和；没有亏损样本时为空，不能据此称稳健。 |
| 收盘盯市最大回撤 | 假设单标的以研究资金完整参与时，收盘净值相对此前峰值的最大下降；不代表盘中最坏路径。 |
| 未结束次数 | 时间分段末尾仍未结束的模拟观察，不计入已实现胜率。 |
| 分环境结果 | 使用当时已知均线把样本分为上涨、下跌、震荡、历史不足；没有对应环境记录时胜率为空。 |
| 成本加倍结果 | 对同一组固定模拟记录重新扣除双倍假设成本，不重新选参，不冒充压力回撤。 |
| 原始输入校验SHA256 | 行情原始临时CSV的字节校验；整套缓存不提交、不上传公开产物。 |
| 协议SHA256 | 固定验证协议的字节校验；用于识别观察结果之后是否改过规则。 |
| 状态 | 数据失败、训练验证不足、留出样本不足、未达到条件，或历史初步满足但仍需未来验证。 |

详细日期分段、成本、参数候选、数据来源及边界见独立研究目录的说明和协议。80%是检验门槛，不是任何未来收益或胜率承诺。

数据校验补丁还记录：`筛选诊断`用于区分历史覆盖、触发次数及净期望筛选；`尾部复权字段未就绪而隔离的日期`列出未补值的尾部日期；`微小价格精度差行数`列出相对一千万分之一容差内的包容差异，超出该容差继续失败。这些字段不改变策略、成本、时间分段或80%门槛。

第二版增加`实际分析输入SHA256`，只校验实际参与规则的价格表；`备用源对照`记录韩股最近20个交集日期收盘的交叉核对结果。`收益口径`明确为价格收益、不计现金分红和汇率。第一版与第二版的数字不得混用或当作同一不可变输入的重复验证。

`尾部OHLC未就绪而隔离的日期`仅列出价格字段尚未完整的尾部日期，实际样本终点据此提前；不插入模拟值，不放过中途异常。
