# 风险标签说明

风险标签用于提醒用户进行人工复核，不代表确定性判断，也不是卖出建议或止损指令。风险扣分必须在报表中单独展示，不能隐藏在综合评分里。

## 1. 标准风险标签

第一版主升浪突破筛选使用以下中文风险标签：

- 距离MA5过远
- 距离MA10过远
- 连续加速过热
- 长上影线
- 缩量冲高
- 盘后走弱
- 杠杆ETF风险
- 流动性不足
- 买卖价差可能偏大
- 高波动风险

## 2. 标签含义

| 风险标签 | 含义 |
| --- | --- |
| 距离MA5过远 | 价格相对 MA5 偏离过大，短线回撤风险上升。 |
| 距离MA10过远 | 价格相对 MA10 偏离过大，趋势虽强但追高风险上升。 |
| 连续加速过热 | 短期连续大涨，可能进入情绪过热阶段。 |
| 长上影线 | 日内冲高后回落明显，说明上方抛压或分歧较大。 |
| 缩量冲高 | 价格上冲但量能不足，突破持续性需要复核。 |
| 盘后走弱 | 盘后价格表现转弱，可能影响下一交易日情绪。 |
| 杠杆ETF风险 | 杠杆 ETF 存在波动放大、路径损耗和长期持有偏离风险。 |
| 流动性不足 | 成交不活跃，可能影响进出效率和价格稳定性。 |
| 买卖价差可能偏大 | 买一卖一价差可能较大，交易摩擦成本较高。 |
| 高波动风险 | 标的波动显著高于普通 ETF 或大盘基准，回撤可能较快。 |

## 3. 风险扣分建议

| 风险标签 | 建议扣分 |
| --- | --- |
| 距离MA5过远 | 4 |
| 距离MA10过远 | 4 |
| 连续加速过热 | 5 |
| 长上影线 | 4 |
| 缩量冲高 | 4 |
| 盘后走弱 | 3 |
| 杠杆ETF风险 | 6 |
| 流动性不足 | 5 |
| 买卖价差可能偏大 | 4 |
| 高波动风险 | 5 |

单个标的累计风险扣分最多扣 20 分。杠杆 ETF 可以进入候选池，但必须标记“杠杆ETF风险”，并在报告中与普通 ETF 区分展示。

## 4. 使用原则

- 风险标签用于提醒人工复核，不用于自动交易。
- 风险标签可以同时出现多个。
- 风险扣分不能超过配置中的上限。
- 杠杆 ETF、高波动标的、流动性不足标的必须优先标记风险。
- 新增风险标签时，必须同步更新 `config/评分权重.yml`、本文件和相关测试。
