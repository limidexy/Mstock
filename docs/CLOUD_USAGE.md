# 云端使用说明

旧电脑不在身边时，可在 GitHub 网页执行小批量真实行情筛选，或仅运行离线源码验收。两个入口均按次运行，不需要旧电脑在线；没有创建定时任务或持续在线网站。

## 真实行情到中文报告

1. 打开 [云端小批量选票](https://github.com/limidexy/Mstock/actions/workflows/cloud-run.yml)。
2. 点击“运行工作流”（Run workflow），选择 `main`。
3. 勾选“允许本轮获取公开日线行情”，保留默认8只股票或填写最多30只股票代码；系统另取QQQ、SPY作为基准。保持未勾选时不会请求行情。
4. 等待运行结束，打开该次运行查看中文说明。失败时查看失败步骤和附件，不能把绿色的源码测试当作选票成功。
5. 在运行页底部下载 `Mstock-report`，解压后打开 `index.html`。请把 `charts/` 和页面放在一起；同时可查看 `候选票.csv`、`空白待校对.csv`、`数据检查.csv`、`运行摘要.json` 和失败清单。附件保留七天。

初始指定池为AA、AAPL、NBIS、MSFT、NVDA、AMD、TSLA、META，只用于接通试运行，不是全市场筛选，也没有运行网上热度榜。候选表保留原评分的全部等级；低等级记录不代表符合主升浪风格。名称是指定样本标记，除基准外的ETF身份没有通过正式股票池核实。

下载复用现有yfinance、Yahoo Chart兜底及Stooq备用逻辑，不引入券商、密钥或新数据源。逐只限速并最多重试一次，每只请求最近300个交易日。运行附件不包含原始日线缓存，也不读取旧电脑人工校对文件。只下载本轮需要的标的，不冒充恢复1414个旧文件。

运行目录必须为空；原始缓存和中间文件使用独立临时目录，不会覆盖原有项目数据。正式评分与报告函数被直接复用，原评分公式、权重和等级阈值不变。

## 数据日期与验收

只使用纽约时间17点前已完成的日线，保守排除当日盘中数据。两个基准最新完整交易日必须一致，且距本轮日期上限不超过七个自然日；这是小批量连通性检查，不是完整交易所日历或全市场新鲜度标准。股票必须与基准日期对齐才参与评分，至少保留130行完整日线供现有滚动指标计算。

零负价格、重复日期、无效成交量、开高低收异常、缺基准、空候选或图表失败均会被记录。基准失效时停止生成成功报告；个别股票下载失败或日期不齐时，报告明确标为部分接通并列出排除项。HTML顶部固定展示实际行情日期和小批量范围。

## 仅运行源码验收

打开 [云端源码验收](https://github.com/limidexy/Mstock/actions/workflows/cloud-check.yml)，点击“运行工作流”（Run workflow）。该入口只执行依赖检查、编译及隔离模拟测试，不下载真实行情。源码、依赖和测试变更时也会自动验收。

两个入口都使用GitHub托管Windows 2022、64位Python 3.12.4和现有固定依赖清单，只读仓库，不提交运行产物。官方Actions固定到已查询的提交。安装环境会获取公开软件依赖，源码验收的业务测试保持离线。
