# 存储股多样本验证

本目录是独立研究实验。80%是验收目标，不是收益或胜率承诺。没有实盘连接、自动下单或当前账户指令，不改变Mstock现有候选评分。

## 先固定协议

`protocol.json`在行情读取和结果观察之前固定。训练使用2021至2022年、验证使用2023年，历史留出使用2024年至已完成日期。请求2020年起数据提供指标预热，上市较晚标的只使用上市以来的真实历史。

候选仅18组：三种规则、三种盈亏倍数和两种最长观察期。仅按训练、验证段筛选，禁止根据留出胜率反复修改。训练或验证不足时保留事先规定的20日高点突破基线，并明确其未完成选参验证。

## 胜率与风险

- 胜率分母为已完成的模拟记录，分子为扣除假设成本后净盈利的记录；保本不算赢，未完成另列。
- 每标的同时只有一笔模拟观察，不叠加、不开空仓、不加额外账户杠杆。
- 信号在完整日线收盘后确定，下一根开盘才可开始。向下跳空按更差开盘计算；同日触及上下边界且开盘在两者之间时按不利边界计算。开盘已经越过收益边界时，保守按边界价格计算，不再假装发生了之后的日内不利触价。
- 单次往返成本假设为普通股0.4%、杠杆产品0.8%，包含费用和滑点的简化模型，不代表用户券商实收费用。另检验成本加倍。杠杆基金产品内部成本已反映于其市场价格，不重复另扣同一成本。
- 使用复权OHLC，包含分红调整，与真实账户的税费、股息现金记账和汇率损益不同。不同币种不拼接成虚假的账户净值。
- 采用Wilson区间，并按进入月份分块重采样2000次；相关性和股票选择偏差仍需未来验证。
- 门槛包括留出段至少100笔、至少12个进入月份、净胜率至少80%、两种95%区间下限至少80%、净期望为正、成本加倍后净期望为正、盈利亏损总额比至少1.2、单标的收盘盯市最大回撤不超过20%。未结束记录还按不赢做保守区间检查。
- 即使满足历史门槛也只标为“初步满足，仍需未来模拟验证”。未达标或样本不足不循环调参“凑80%”。

## 数据边界

六个代码为000660.KS、005930.KS、MU、SNDK、SKHY和7709.HK。海力士相关三个代码属于一个公司组，不合并成三份独立公司证据。

行情通过公开Yahoo Finance数据、固定版本yfinance读取。记录来源、时区、获取时间、行数、日期和输入SHA256；缺失、过期或异常数据必须失败，不能补模拟行情。成交量跨来源差异尚未解决，因此本轮不把成交量用作信号。

原始行情只写运行器的临时`raw-private`目录，不提交Git、不上传公开报告产物。公开产物仅包括协议、审计元数据、验证结果和研究模拟记录。

三段重叠规则为简化几何定义，不声称实现严格缠论。此研究存在当前标的选择偏差，近期行情也已被观察过；历史时间留出不等于严格盲测，更不能保证未来80%。

## 运行

默认不联网。边界测试只使用内存中的小型样例：

```sh
python research/memory_validation/validate.py --self-test
```

本轮用户已要求扩大公开行情分析，云端研究任务显式传入联网参数：

```sh
python research/memory_validation/validate.py --allow-network --output-dir 临时研究输出
```

输出的`验证结果.json`和`验证摘要.md`保留所有失败和未达标情况。胜率不是唯一验收项，也不是交易承诺。

## 首次执行与数据校验补丁

第一轮执行为GitHub Actions运行41694348694，保留原始结果。海力士与三星触发OHLC包容关系检查，7709尾部复权字段无效；没有把失败当成0收益。数据校验补丁仅允许相对价格一千万分之一的浮点误差，超限继续失败；尾部复权未就绪时隔离该尾部并披露实际终点，不补值。中途无效记录仍然失败。

补丁不改变观察规则、成本、训练验证留出区间和80%门槛。新增筛选诊断区分历史覆盖、触发次数和净期望筛选，不把所有未通过都误称为“历史不足”。
